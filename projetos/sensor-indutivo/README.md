# Simulador do sensor indutivo

Projeto autocontido do laboratório de regulagem de um sensor indutivo M18 sobre formas de 90 g.

## Conteúdo

- `simulador/`: aplicação web offline, cálculo didático, cenários e testes.
- `modelos/`: modelos Blender, GLB e prévias usados pela aplicação.
- `referencias/`: arquivos originais e fotografias preservados como fonte.
- `ferramentas/`: scripts Blender que geram e preparam os modelos.

## Desenvolvimento

Entre em `simulador/` e execute `npm ci`, `npm test` e `npm run build`. A operação detalhada e as limitações do modelo estão no LEIA-ME do simulador.
